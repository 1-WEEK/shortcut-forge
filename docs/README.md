# Documentation Index

This directory centralizes the package documentation and request/response examples.

- `SPEC.md` — requirements and API contract
- `PLAN.md` — implementation steps without prescribing a stack
- `RUST_ARCHITECTURE.md` — concrete Rust reference architecture
- `openapi.yaml` — static machine-readable API contract for downstream callers
- `IMPLEMENTATION_PROMPT.md` — prompt to paste into the Mac-side agent
- `contracts/` — request and response examples
- `examples/` — minimal Cherri source and sample build payloads
